# A3 个性化学习多智能体系统 - 开发说明书

## 1. 项目概述

### 1.1 项目背景
本项目为第十五届中国软件杯A3赛题参赛作品，开发一套面向《人工智能导论》课程的AI个性化学习系统。

### 1.2 核心目标
- 基于讯飞星火大模型实现对话式学生画像构建
- 搭建多智能体协同的个性化资源生成系统
- 构建课程知识图谱，实现自适应学习路径规划
- 提供流式输出、Markdown+LaTeX+Mermaid渲染等交互能力

## 3. 数据库设计

### 3.1 核心表（6张）

**student_profile** - 学生画像表
- id, student_name, base_level(1-5), cognitive_style, learn_preference, error_type, learn_speed(1-5), learn_goal

**knowledge_point** - 知识点节点表
- kp_id, name, description, chapter_id, difficulty(1-5), mastery_threshold

**kp_dependency** - 知识点依赖边表
- edge_id, from_kp_id, to_kp_id, dependency_type, weight

**student_mastery** - 学生知识点掌握度表
- id, student_id, kp_id, mastery(0-1), last_learn_time

**learning_resource** - 学习资源表
- res_id, kp_id, res_type, content, create_time

**chat_record** - 对话记录表
- id, student_id, role, content, create_time

## 4. 多智能体系统设计

### 4.1 架构
采用1协调Agent + 5执行Agent架构：

| Agent | 模型 | 职责 |
|-------|------|------|
| 协调Agent | - | 请求分发、并行调度、结果聚合、异常处理 |
| 诊断Agent | Spark Lite | 对话式特征抽取、画像构建、知识断点定位 |
| 教案Agent | Spark Ultra | Markdown教案+LaTeX公式生成 |
| 习题Agent | Spark Ultra | 针对性练习题+解析生成 |
| 代码Agent | Spark Pro | Python代码+逐行注释生成 |
| 思维导图Agent | Spark Lite | Mermaid思维导图生成 |

### 4.2 通信协议
统一JSON消息格式：
```json
{
  "message_id": "uuid",
  "sender": "agent名称",
  "receiver": "目标agent",
  "timestamp": 1718000000,
  "task_type": "任务标识",
  "payload": {},
  "status": "pending/success/fail"
}
```

### 4.3 状态管理（三级）
- 全局状态：PostgreSQL（永久存储）
- 会话状态：Redis（2小时有效期）
- Agent局部状态：Astron内存（任务结束销毁）

## 5. 核心算法

### 5.1 自适应学习路径算法
1. 输入：知识图谱DAG + 学生全量掌握度
2. 筛选：掌握度 < 0.6 且所有前置知识点掌握度 >= 0.6
3. 排序：按优先级分数 = (6-难度) × 依赖权重 降序
4. 输出：有序学习列表

### 5.2 前置知识点校验算法
遍历目标知识点所有强依赖边，批量查询掌握度，阈值0.6判定。

### 5.3 知识断点定位算法
基于对话内容+测验结果，结合知识图谱依赖关系，定位根级薄弱知识点。

复制 `backend/config/.env.example` 为 `backend/config/.env`，填入讯飞API密钥。
