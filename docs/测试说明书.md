# A3 个性化学习多智能体系统 - 测试说明书

## 1. 测试概述

### 1.1 测试目标
验证系统所有必做功能的正确性、性能和稳定性，确保满足第十五届软件杯A3赛题评审要求。

### 1.2 测试环境
- 后端：Python 3.10+ / FastAPI
- 前端：React 18 / Node 20
- 数据库：PostgreSQL 16 / Chroma 0.5 / Redis 7
- 部署：Docker + Docker Compose

## 2. 功能测试用例

### TC-001: 多轮对话生成学生画像

**前置条件：** 系统正常运行，后端API可用

**测试步骤：**
1. 访问 http://localhost:3000，点击"开始学习"
2. 进入对话画像页面
3. 依次输入以下回答：
   - "我是计算机专业大二学生"
   - "编程基础一般，Python比较熟练"
   - "对机器学习很感兴趣"
   - "数学基础不太好，希望从基础讲起"
   - "我想参加AI相关的竞赛"
4. 观察AI回复和画像标签变化

**预期结果：**
- AI能自然引导对话，每次只问1-2个问题
- 对话结束后，画像面板显示6个维度标签
- 画像数据正确保存到localStorage

**通过标准：** 画像6个维度全部填充

### TC-002: 多智能体生成个性化资源

**前置条件：** 已完成对话画像

**测试步骤：**
1. 进入"知识点学习"页面
2. 从左侧列表选择一个知识点
3. 等待资源生成完成
4. 切换查看教案/习题/代码/思维导图标签页

**预期结果：**
- 显示"多智能体正在并行生成资源..."进度提示
- 教案标签页：显示Markdown格式内容，含LaTeX公式
- 习题标签页：显示针对性练习题和解析
- 代码标签页：显示Python代码和逐行注释
- 思维导图标签页：显示Mermaid思维导图

**通过标准：** 4类资源全部正常生成和渲染

### TC-003: 前置知识点校验

**前置条件：** 知识图谱数据已导入

**测试步骤：**
1. 选择一个有前置依赖的知识点（如kp0102图灵测试）
2. 若前置知识点（kp0101人工智能定义）掌握度 < 0.6
3. 观察页面提示

**预期结果：**
- 显示橙色警告卡片："需要先学习以下前置知识点"
- 列出缺失的前置知识点名称和掌握度

**通过标准：** 前置校验正确触发并显示

### TC-004: 自适应学习路径

**前置条件：** 学生画像已完成

**测试步骤：**
1. 进入"学习路径"页面
2. 观察推荐的学习列表
3. 点击"标记已掌握"按钮

- 标记已掌握后，该知识点从列表中移除
- 路径自动重排

**通过标准：** 路径正确排序，动态更新正常

## 3. 性能测试

### PT-001: 对话响应时间
- **指标：** ≤3秒
- **方法：** 发送10次对话，记录响应时间
- **工具：** 浏览器DevTools Network面板

### PT-002: 单类资源生成时间
- **指标：** ≤5秒
- **方法：** 选择知识点，记录资源生成时间
- **工具：** 浏览器DevTools Network面板

### PT-003: 全套资源生成时间
- **指标：** ≤10秒
- **方法：** 选择知识点，记录5类资源全部生成时间
- **工具：** 浏览器DevTools Network面板

### PT-004: 并发测试
- **指标：** 50用户同时在线无崩溃
- **方法：** 使用Apache Bench或JMeter
- **命令：** `ab -n 100 -c 50 http://localhost:8000/health`

## 4. 边界测试

### BT-001: 知识点掌握度临界值
- 设置掌握度为0.59，验证前置校验触发
- 设置掌握度为0.60，验证前置校验通过

### BT-002: 前置知识缺失场景
- 选择高级知识点，确保前置知识全部未掌握
- 验证系统正确提示所有缺失的前置知识

### BT-003: API重试异常场景
- 模拟讯飞API不可用
- 验证系统返回友好错误提示，不崩溃

### BT-004: 空输入处理
- 发送空消息
- 验证系统不处理空输入
