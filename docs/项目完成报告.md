# A3 个性化学习多智能体系统 — 项目完成报告

## 第十五届软件杯A3赛题

---

## 一、项目概述

开发一套面向高校课程的 AI 个性化学习系统，依托讯飞星火大模型 + 知识图谱 + 多智能体协同，实现：

- **对话式学生画像构建**（6 维动态画像）
- **多智能体协同生成个性化学习资源**（6 类资源）
- **知识图谱驱动的自适应学习路径**
- **双课程支持**（人工智能导论 + 软件安全技术，对话自动匹配）

---

## 二、技术栈

| 层 | 技术 |
|----|------|
| 后端 | Python 3.10+ / FastAPI / SQLAlchemy / PostgreSQL 16 |

## 三、多智能体架构（6 Agent）

```
用户请求 → 协调Agent（Coordinator）
              ├── 诊断Agent（Diagnose）    → 6轮固定对话构建学生画像
              ├── 教案Agent（Lesson）      → Markdown 教案 + LaTeX 公式
              ├── 习题Agent（Exercise）    → 针对性练习题 + 详细解析
              ├── 代码Agent（Code）        → 可运行 Python 代码 + 注释
              ├── 思维导图Agent（Mindmap） → LLM 生成知识点脑图
              ├── 拓展阅读Agent（Reading） → 延伸文献/技术脉络/跨学科
              └── 视频推荐Agent（Video）   → B站/YouTube/MOOC 搜索推荐
```

**协调器特性：**
- 6 个 Agent 并行启动（asyncio.gather）
- 信号量控制并发（Semaphore(3)），避免 API QPS 限流
- 每个 Agent 有 3 次重试 + QPS 限流退避
- 流式 SSE 端点实时推送进度事件

## 四、核心功能

### 4.1 对话式学习画像

- 6 轮固定对话：选课 → 知识基础 → 学习目标 → 资源偏好 → 认知风格 → 画像
- 代码控流程，LLM 只负责自然回应和关键词解析
- 6 个维度：知识基础(1-5)、认知风格、学习偏好、易错类型、学习速度(1-5)、学习目标
- 画像变化历史记录
- 前端实时画像标签展示 + 知识漏洞看板

### 4.2 双课程支持

- 知识点带 `course` 字段区分课程
- 对话中关键字自动识别（机器学习→AI；网络安全→软件安全）
- 前端按课程过滤知识点列表
- 两门课共计 225 个知识点、204 条依赖

| 课程 | 知识点数 | 章节数 |
|------|---------|--------|
| 人工智能导论 | 102 | 12 |
| 软件安全技术 | 123 | 15 |

### 4.3 6 类个性化资源生成

| 资源类型 | Agent | 内容 |
|---------|-------|------|
| 教案 (lesson) | 教案Agent | Markdown 讲义，|LaTeX 公式，知识点超链接 |
| 习题 (exercise) | 习题Agent | 针对性练习题 + 详细解析 + 易错点提示 |
| 代码 (code) | 代码Agent | 可运行 Python 代码 + 逐行注释 |
| 思维导图 (mindmap) | 思维导图Agent | LLM 生成脑图（5 分支：前置知识/核心概念/方法/应用/易错点） |
| 拓展阅读 (reading) | 拓展阅读Agent | 文献推荐 + 技术发展脉络 + 跨学科联系 + 前沿动态 |
| 视频推荐 (video) | 视频推荐Agent | B站/YouTube/MOOC 搜索词 + 学习建议 + 自评指引 |

**特性：**
- 并发生成（信号量 3 路，约 30-40 秒完成全套）
- 流式 SSE 端点（`/api/resource/generate/stream`）
- 前端进度条 + 各 Agent 状态卡片
- 缓存机制（同知识点二次访问秒出）
- Profile 感知：基础好的学生→精简要点；基础差的学生→详细解释

### 4.4 知识图谱 + 学习路径

- 三层 DAG：课程 → 章节 → 知识点
- 前置校验：访问知识点自动检测前置依赖掌握度
- 知识点跳转：资源文档内点击跳转对应学习页
- 自适应学习路径：
  - DAG 拓扑排序 + 掌握度加权
  - 学习速度/基础水平个性化加权
  - 完成学习后自动重算路径

### 4.5 RAG 知识库检索

- Chroma 向量库存储知识库文档
- 38 篇分章节讲义自动切片入库
- 资源生成时检索相关上下文，防幻觉

### 4.6 内容安全

- 集成敏感词过滤
- 对话输入 + AI 输出双向检测

## 五、API 接口总览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/chat/diagnose` | 对话画像（非流式） |
| POST | `/api/chat/diagnose/stream` | 对话画像（SSE 流式） |
| POST | `/api/chat/reset` | 重置学生全部数据 |
| GET | `/api/chat/profile_history/{student_id}` | 画像变化历史 |
| POST | `/api/chat/seed_virtual_students` | 导入 10 组虚拟学生 |
| POST | `/api/resource/generate` | 资源生成（非流式） |
| POST | `/api/resource/generate/stream` | 资源生成（SSE 流式 + 进度） |
| GET | `/api/path/get_path` | 自适应学习路径 |
| POST | `/api/path/complete_kp` | 标记知识点已完成 |
| PUT | `/api/path/update_mastery` | 更新掌握度 |
| GET | `/api/kg/knowledge_points` | 知识点列表（支持 course/chapter_id 过滤） |
| GET | `/api/kg/knowledge_point/{kp_id}` | 知识点详情 |
| GET | `/api/kg/check_pre/{kp_id}/{student_id}` | 前置校验 |
| GET | `/api/kg/graph` | 知识图谱结构 |
| GET | `/api/kg/courses` | 可用课程列表 |

## 七、前端页面

### 3 个主页面

1. **首页**：输入名字开始学习
2. **对话画像页**：聊天框 + 右侧画像面板 + 画像历史时间线
3. **知识点学习页**：知识点列表 + 6 Tab 资源（教案/习题/代码/思维导图/拓展阅读/视频推荐）+ 知识漏洞看板

### 核心组件

- `ChatBox`：流式对话渲染
- `ResourceCard`：Markdown + LaTeX 渲染 + 知识点超链接
- `MindMap`：markmap 脑图渲染 + 分支着色
- `KnowledgeVulnerabilityBoard`：薄弱知识点列表 + 画像摘要
- `LearningPathPanel`：学习路径列表 + 进度

## 九、关键修复记录

| # | 问题 | 根因 | 修复 |
|---|------|------|------|
| 1 | AppIdNoAuthError | 代码硬编码 X1.5 端点，用户开通的是 Ultra-32K | 所有 Agent 改为走 Ultra (v3.5/chat, domain: generalv3.5) |
| 2 | 前端请求不通 | Vite 代理 localhost:8000，容器内 localhost 指自己 | 改为 Docker 服务名 backend:8000 |
| 3 | 数据库连接断开 | 长任务期间连接超时 | 添加 pool_pre_ping + pool_recycle |
| 4 | Agent 串行执行 | 代码串行 + 2s 延迟 | asyncio.gather 并行 + Semaphore(3) 控并发 |
| 5 | 资源生成无流式 | 普通 POST 模式 | 新增 SSE 端点 + 前端进度条 |
| 6 | 思维导图为空模板 | 不调 LLM，只拼固定字符串 | 改为调用 LLM 生成 5 分支脑图 |
| 7 | 仅 4 类资源 | 赛题要求 ≥5 类 | 新增拓展阅读 + 视频推荐 Agent |
| 8 | 课程死磕软件安全 | 知识图谱单一课程 | 双课程加载 + 对话自动匹配 + 前端过滤 |
| 9 | 诊断对话死循环 | LLM 记不住状态 | 重写为代码控流程 6 轮固定对话 |
| 10 | Markdown 不渲染 | 缺少 github-markdown-css | 安装 + 全局导入 + KaTeX CSS |
| 11 | 知识漏洞看板点击无效 | 路由 /learning 不存在 | 改为切换 Tab + 分发 navigateToKp 事件 |
| 12 | 登录页残留旧数据 | localStorage 持久化 | 首页挂载清理 + autocomplete=off |
| 13 | 聊天消息闪现消失 | typewriter 动画与静态消息时序冲突 | 去掉动画中间态，直接写 chatHistory |
| 14 | RAG 知识库为空 | Docker 路径解析错误 | 多级路径兼容 + 懒加载 |
| 15 | ProfileHistory 缺 course 字段 | 模型新加字段未同步 | ALTER TABLE 添加 |
| 16 | ONNX 模型下载阻塞启动 | Chroma 嵌入模型 79MB 下载 | RAG 改为懒加载，不阻塞启动 |
| 17 | QPS 限流导致生成失败 | 6 路并发 > API 承受 | Semaphore(3) 控并发数 |
