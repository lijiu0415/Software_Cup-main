# 第1章 人工智能概述

## 1.1 人工智能的定义

人工智能（Artificial Intelligence, AI）是计算机科学的一个分支，致力于创建能够执行通常需要人类智能的任务的系统。

**核心能力：**
- 感知环境：通过传感器获取信息
- 推理思考：基于知识进行逻辑推理
- 自主决策：在无人工干预下做出选择
- 执行行动：通过执行器完成操作

## 1.2 图灵测试

图灵测试由Alan Turing于1950年提出，用于评估机器是否具有智能。

**测试方法：** 人类评判员通过文本界面同时与机器和人类对话，若评判员无法区分两者，则认为机器通过测试。

**局限性：**
- 仅测试外部行为，不涉及内部理解能力
- 依赖评判员的主观判断
- 忽略感知和行动能力

## 1.3 AI发展简史

| 时期 | 事件 |
|------|------|
| 1950 | 图灵发表《计算机器与智能》，提出图灵测试 |
| 1956 | 达特茅斯会议，"人工智能"术语正式诞生 |
| 1966 | ELIZA聊天程序，最早的NLP尝试 |
| 1997 | IBM深蓝击败国际象棋冠军 |
| 2012 | AlexNet在ImageNet竞赛中大获成功，深度学习崛起 |
| 2016 | AlphaGo击败围棋冠军李世石 |
| 2022 | ChatGPT发布，大语言模型时代到来 |

## 1.4 AI三大流派

| 流派 | 核心思想 | 代表方法 |
|------|---------|---------|
| 符号主义 | 符号推理 | 逻辑编程、专家系统 |
| 连接主义 | 模拟神经网络 | 深度学习、神经网络 |
| 行为主义 | 感知-动作控制 | 强化学习、机器人控制 |

## 1.5 弱AI与强AI

- **弱AI（Narrow AI）**：专注于特定任务的AI系统，当前所有AI均属此类
- **强AI（AGI）**：具有通用人类认知能力的AI系统（尚未实现）

## 1.6 AI应用领域

1. **自然语言处理**：机器翻译、文本生成、情感分析
2. **计算机视觉**：图像识别、目标检测、人脸识别
3. **推荐系统**：电商推荐、内容推荐
4. **自动驾驶**：感知、决策、控制
5. **医疗诊断**：影像分析、药物发现
6. **金融风控**：欺诈检测、量化交易
