# 第2章 智能体与环境

## 2.1 智能体的分类

智能体（Agent）是能够感知环境并通过行动影响环境的实体。

**按智能程度分类：**
- 简单反射型智能体：基于当前感知直接行动
- 基于模型的反射型智能体：维护内部状态
- 基于目标的智能体：考虑未来行动结果
- 基于效用的智能体：评估行动的效用值
- 学习型智能体：从经验中学习改进

## 2.2 智能体环境类型

| 环境属性 | 说明 |
|---------|------|
| 可观察性 | 完全可观察 / 部分可观察 |
| 确定性 | 确定性 / 随机性 |
| 静态性 | 静态 / 动态 |
| 离散性 | 离散 / 连续 |
| 单/多智能体 | 单智能体 / 多智能体 |

## 2.3 感知与动作

**感知（Perception）**：智能体通过传感器获取环境信息
**动作（Action）**：智能体通过执行器对环境产生影响

感知-动作循环：感知 → 思考 → 行动 → 感知...

## 2.4 理性智能体

理性智能体（Rational Agent）是指在所有可能的感知序列中，选择期望最大化其性能度量的行动的智能体。

**理性决策四要素：**
1. 性能度量（Performance Measure）
2. 先验知识（Prior Knowledge）
3. 可执行行动（Actions）
4. 感知序列（Percept Sequence）

## 2.5 任务环境与PEAS描述

PEAS是描述智能体任务环境的框架：
- **P**erformance（性能度量）
- **E**nvironment（环境）
- **A**ctuators（执行器）
- **S**ensors（传感器）

**示例：自动驾驶汽车**
- P：安全、快速、合法到达目的地
- E：道路、其他车辆、行人、交通信号
- A：方向盘、油门、刹车、转向灯
- S：摄像头、激光雷达、GPS、速度计
