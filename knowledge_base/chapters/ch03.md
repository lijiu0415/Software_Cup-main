# 第3章 搜索与推理

## 3.1 搜索问题的基本框架

搜索算法通过在状态空间中寻找从初始状态到目标状态的路径来解决问题。

**搜索问题五要素：**
1. 初始状态（Initial State）
2. 行动集合（Actions）
3. 状态转移模型（Transition Model）
4. 目标测试（Goal Test）
5. 路径代价（Path Cost）

## 3.2 无信息搜索（盲目搜索）

### 广度优先搜索（BFS）
- 逐层扩展节点
- 完备且最优（等代价时）
- 时间复杂度：O(b^d)
- 空间复杂度：O(b^d)

### 深度优先搜索（DFS）
- 沿一条路径深入到底
- 不完备（可能陷入无限循环）
- 时间复杂度：O(b^m)
- 空间复杂度：O(bm)

## 3.3 代价一致搜索（UCS）

按路径代价g(n)递增顺序扩展节点，保证找到最优解。

## 3.4 A*搜索算法

A*搜索使用评估函数f(n) = g(n) + h(n)：
- g(n)：从起点到n的实际代价
- h(n)：从n到目标的启发式估计

**最优性条件：** 启发式函数h(n)必须满足可采纳性（不高估实际代价）

## 3.5 启发式函数设计

好的启发式函数应：
- 可采纳性：h(n) ≤ h*(n)
- 一致性：h(n) ≤ c(n,a,n') + h(n')

## 3.6 局部搜索算法

适用于优化问题，不需要找到最优解，只需找到足够好的解：
- 爬山法（Hill Climbing）
- 模拟退火（Simulated Annealing）
- 遗传算法（Genetic Algorithm）
