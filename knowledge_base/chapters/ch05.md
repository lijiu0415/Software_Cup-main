# 第5章 机器学习基础

## 5.1 机器学习概述

机器学习（Machine Learning）是AI的核心分支，通过数据驱动让计算机自动学习模式和规律。

**三大类型：**
- **监督学习**：从标注数据学习映射关系
- **无监督学习**：从未标注数据发现隐藏结构
- **强化学习**：通过环境交互学习最优策略

## 5.2 监督学习基本概念

**训练集**：用于学习模型参数的数据
**测试集**：用于评估模型泛化能力的数据
**特征（Feature）**：输入变量
**标签（Label）**：输出变量

## 5.3 线性回归

线性回归是最基础的监督学习算法，用于预测连续值。

$$h_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + ... + \theta_n x_n = \theta^T x$$

**损失函数（均方误差）：**
$$J(\theta) = \frac{1}{2m}\sum_{i=1}^{m}(h_\theta(x^{(i)}) - y^{(i)})^2$$

**梯度下降更新规则：**
$$\theta_j := \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j}$$

## 5.4 逻辑回归

逻辑回归用于二分类问题，使用sigmoid函数：

$$h_\theta(x) = \frac{1}{1 + e^{-\theta^T x}}$$

## 5.5 决策树与集成学习

**决策树**：通过一系列if-else规则进行分类
**集成学习**：组合多个弱学习器构建强学习器
- Bagging（随机森林）
- Boosting（AdaBoost, XGBoost）

## 5.6 支持向量机SVM

SVM寻找最大化类别间隔的最优分离超平面：

$$\min_{w,b} \frac{1}{2}\|w\|^2 \quad s.t. \quad y_i(w^Tx_i + b) \geq 1$$

## 5.7 无监督学习

**聚类**：将相似样本分组（K-Means, DBSCAN）
**降维**：减少特征维度（PCA, t-SNE）

## 5.8 模型评估

| 指标 | 公式 | 说明 |
|------|------|------|
| 准确率 | (TP+TN)/(TP+TN+FP+FN) | 正确预测的比例 |
| 精确率 | TP/(TP+FP) | 预测为正中实际为正的比例 |
| 召回率 | TP/(TP+FN) | 实际为正中被正确预测的比例 |
| F1 | 2PR/(P+R) | 精确率和召回率的调和平均 |
